# Anatomy Calisthenics

An anatomy-based calisthenics platform designed to help athletes build strength and muscle using effective bodyweight exercises.

## Features

- Interactive muscle group selection
- Anatomy visualization
- 10+ exercises for each muscle group
- Detailed exercise instructions
- Target muscle explanations
- Difficulty ratings
- Common mistakes and safety tips
- Mobile-friendly design
- No registration required

## Muscle Groups

- Abs
- Obliques
- Biceps
- Triceps
- Shoulders
- Back

## Goal

Provide scientifically selected calisthenics exercises that maximize muscle activation while avoiding ineffective movements.

- HTML
- CSS
- JavaScript
